- 0.25Y 37.8bp: BOOT L10 = 라이브 3M/2(1.211%) 인데 6M 이하 마디는 잔존값(2.795%) — 시트 안 라이브/잔존 혼합 결함(감사인 질의 회신 (*1) 2.765%/11.854% 와 일치하는 2024-12-31 값이 남아 있음). 엔진 문제 아님.
- 그 외 중점 ≤1.45bp: BOOT 는 인접 기간현물의 산술평균(L 열), 엔진은 log-DF 선형 — 관례 차이.
- DATA!F·BM row 6/11 은 이 BOOT 값을 MF_INTERPOL(연복리 현물 선형·원점 앵커)로 격자에 올린 것(에이전트 재계산 비트 일치)이므로 별도 대조하지 않았다. DATA!F 는 2024-12-31 기준 YEARFRAC 로 계산된 잔존값이라 현 기준일 커브와 최대 8.6e-2 차이(원본 파일 결함, 에이전트 명세).

## C3. KBI xlsm 'Bootstrapping_평가자'(복사본) vs 엔진 LINEAR

- 시트 마디 '현물' − YTM 복리변환((1+y/m)^m−1 → 연속; 3M 은 4·ln(1+y/4), 9M 은 (ln(1+y/4)+ln(1+y/2))/0.75): RF·RD 모두 **5e-12bp** → 시트는 부트스트랩이 아니라 YTM 을 현물로 간주한 변환이다(라벨 '현물이자율 추정' 과 달리 이표 재투자 가정 없음).
- 엔진 − 시트 마디(bp): RF 0.25Y −3.39(§C1.2), 0.5Y 0, 0.75Y +2.12, 1Y +0.10, 1.5Y +0.34, 2Y +0.36, 2.5Y +0.87, 3Y +0.60, 4Y +1.48, 5Y +1.76, 7Y +2.66, 10Y +1.93 ; RD(사모 BB+) 0.25Y 0, 0.5Y +0.76, 1Y +3.38, 2Y +14.6, 3Y +30.0, 5Y +44.1, 7Y +54.8, 10Y +79.3 — 우상향 커브에서 현물 > YTM 인 정상적인 이표 효과.
- RF 주간 격자(연속현물 선형): 엔진 대비 max 6.5bp, mean 1.9bp. RD 주간 블록(행 221~223)은 RF 블록(행 100~102)과 521셀 전부 동일 → 시트 참조 버그, 비교 생략.
